## 3. 答辩故事线（3 分钟讲稿草稿）

> **开场**：评委好，我们做的是"智学伴"——一个结合图书馆藏书的个性化 AI 学习规划智能体。
>
> **痛点**：现在的 AI 学习助手（如豆包、多邻国）都是通用的，不知道你手边有什么书、你的时间怎么安排、你学得怎么样。图书馆里 130 本计算机书闲置，学生不知道从哪开始。
>
> **解决方案**：
> 1. 用户说"我想学 Redis"，AI 出 3 道诊断题了解你的起点
> 2. AI 参考 GitHub roadmap 拆出 10 个学习点，每个点配图书馆里对应的书
> 3. 纯 Java 排期器把点铺到日历上（倒排、前置依赖、每日时长上限）
> 4. 学完一个点提交练习，AI 点评打分，掌握度动态更新
> 5. 不及格或没时间，AI 生成重排方案，你确认后才执行
>
> **技术亮点**：
> - 统一模型网关：强/弱/Mock 三档，每次调用记 Token 账本
> - 移动云 MoMA DeepSeek-V3.2 调用
> - FSRS 间隔重复算法
> - 两步确认机制（AI 只出方案，用户确认才改库）
>
> **社会效益**：让图书馆藏书真正用起来，让普通人按需学习而不是盲目刷题。
